### 1️⃣ Offline YouTube Summarizer

<table>
<tr>
<td width="70%">

**A fully offline GenAI pipeline** that transcribes YouTube videos using OpenAI **Whisper** and generates structured, concise summaries with **Llama 3** — no API key, no internet dependency after setup.

**Key Features:**
- 🎙️ Accurate speech-to-text via Whisper (local inference)
- 🧠 Summarization powered by Llama 3 via Ollama
- 🖥️ Clean Streamlit UI with video URL input
- 🔒 Fully private — nothing leaves your machine
- ⚡ Chapter-aware summary support

**Impact:** Eliminates reliance on paid summarization APIs; works air-gapped for sensitive content.

<details>
<summary>🔧 <strong>Quick Start — YouTube Summarizer</strong></summary>

```bash
# 1. Clone the repo
git clone https://github.com/Vijay3alaji/youtube-summarizer.git
cd youtube-summarizer

# 2. Create & activate virtual environment
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Pull Llama 3 model via Ollama
ollama pull llama3

# 5. Run the app
streamlit run app.py
```

> **Requirements:** Python 3.10+, [Ollama](https://ollama.ai), ffmpeg

**Example usage in code:**
```python
from summarizer import YoutubeSummarizer

summarizer = YoutubeSummarizer(model="llama3", whisper_size="base")
result = summarizer.run("https://www.youtube.com/watch?v=EXAMPLE")

print(result.summary)
# → "This video explains transformer architecture in 3 key sections: ..."
```

### 2️⃣ SOQL Chatbot

<table>
<tr>
<td width="70%">

**An NL-to-SOQL translation engine** that converts plain English business questions into valid Salesforce Object Query Language queries. Evolved from a fine-tuned **CodeT5** baseline to a **Llama**-powered few-shot system.

**Key Features:**
- 💬 Natural language → SOQL query generation
- 🔄 Model evolution: CodeT5 (fine-tuned) → Llama (few-shot)
- 🗄️ Schema-aware query construction
- ✅ Query validation & error handling layer
- 📊 Evaluated on custom NL-SOQL benchmark dataset

**Impact:** Reduces time for non-technical Salesforce admins to extract data insights from hours to seconds.

## 🏗️ Architecture Overview

<details>
<summary><strong>Offline YouTube Summarizer — System Architecture</strong></summary>

```
┌─────────────────────────────────────────────────────────┐
│                    Streamlit Frontend                   │
│              [ YouTube URL Input + UI ]                 │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────────────┐
│               Audio Extraction Layer                     │
│         yt-dlp → MP3/WAV (local download)               │
└──────────────────────┬───────────────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────────────┐
│             OpenAI Whisper (Local Inference)              │
│       base / small / medium model → Raw Transcript       │
└──────────────────────┬───────────────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────────────┐
│           Chunking & Context Management                  │
│      LangChain TextSplitter → Overlapping Chunks        │
└──────────────────────┬───────────────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────────────┐
│          Llama 3 (via Ollama — fully local)              │
│    Map-Reduce Summarization → Structured Markdown       │
└──────────────────────┬───────────────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────────────┐
│                  Streamlit Output Panel                  │
│         Summary + Key Points + Timestamps               │
└──────────────────────────────────────────────────────────┘
```

</details>

<details>
<summary><strong>SOQL Chatbot — Model Evolution Path</strong></summary>

```
Phase 1: CodeT5 Fine-tuning
  Dataset → Tokenization → CodeT5-base → Fine-tune (NL→SOQL pairs)
  → 61% Exact Match on validation set

Phase 2: Llama 3 Few-shot
  Schema Injection → Few-shot Examples → Llama 3 (Ollama)
  → 74% Exact Match | 81% Execution Accuracy

Phase 3 (Planned): RAG-augmented generation
  Schema Vector Store (FAISS) → Dynamic schema retrieval
  → Context-aware generation for multi-object queries
```

</details>

<details>
<summary><strong>YouTube Summarizer — API Reference</strong></summary>

```python
class YoutubeSummarizer:
    """
    Offline YouTube video summarizer using Whisper + Llama 3.
    
    Args:
        model (str): Ollama model name. Default: "llama3"
        whisper_size (str): Whisper model size. Options: tiny|base|small|medium|large
        chunk_size (int): Token chunk size for map-reduce. Default: 2000
        language (str): Transcript language hint. Default: "en"
    """

    def run(self, url: str) -> SummaryResult:
        """
        Full pipeline: download → transcribe → summarize.
        
        Returns:
            SummaryResult:
                .summary (str)        — Full structured summary
                .key_points (list)    — Bullet-point highlights
                .transcript (str)     — Raw Whisper transcript
                .duration_sec (int)   — Video duration
        """
```

</details>

<details>
<summary><strong>SOQL Chatbot — API Reference</strong></summary>

```python
class SOQLChatbot:
    """
    Natural language to SOQL query generator.
    
    Args:
        model_type (str): "codet5" | "llama". Default: "llama"
        schema_path (str): Path to Salesforce schema JSON
        validate (bool): Run query validation before returning. Default: True
    """
    
    def generate(self, nl_query: str) -> SOQLResult:
        """
        Args:
            nl_query (str): Plain English question about Salesforce data
        
        Returns:
            SOQLResult:
                .soql (str)           — Generated SOQL query
                .confidence (float)   — Model confidence score
                .objects_used (list)  — SF objects referenced
                .is_valid (bool)      — Passes SOQL syntax check
        """
```
